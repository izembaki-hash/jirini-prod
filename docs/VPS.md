# دليل اختيار الـVPS والنشر عليه

> الهدف: تشغيل `docker compose` (Postgres + API + Web + Caddy) بموثوقية لعشرات المحلات، بزمن استجابة جيد للجزائر.

## المواصفات المطلوبة (البداية)

| المورد | الحد الأدنى | ملاحظة |
|---|---|---|
| CPU | 2 vCPU | تكفي حتى ~50 محلاً نشطاً |
| RAM | 4 GB | استهلاكنا الخامل < 1GB |
| قرص | 60–80 GB SSD/NVMe | قاعدة + نسخ + صور |
| نظام | Ubuntu 24.04 LTS | أو 22.04 |
| موقع | فرنسا / ألمانيا / هولندا | ping من الجزائر 30–70ms. تجنّب أمريكا (+150ms) |

## التوصية

### الخيار الأول: Hetzner (الأفضل قيمة) — إذا توفر دفع دولي
- الخادم: **CX32** (2 vCPU / 4GB / 160GB) ≈ **€6.7/شهر** (~1000 دج) — Falkenstein أو Nuremberg.
- لماذا: أفضل سعر/أداء في أوروبا، شبكة ممتازة، Snapshots رخيصة، لوحة بسيطة.
- الشرط: بطاقة دولية (Visa/Mastercard بعملة صعبة) أو Wise/Paysera — البطاقات الجزائرية المحلية (CIB/EDAHABIA) **لا تُقبل غالباً** للدفع الدولي.

### الخيار الثاني: مزوّد جزائري (الأسهل دفعاً)
- إذا الدفع المتاح **DZD فقط** (CCP/CIB/تحويل): اختر مزوداً جزائرياً (Icosnet، Djezzy Cloud، Satlink، أو مستضيفين محليين معروفين).
- اشترط قبل الدفع: **KVM** (لا OpenVZ)، صورة Ubuntu 24.04، دخول root عبر SSH، خيار Snapshot/Backup، وفتح المنافذ 22/80/443.
- المقايضة: سعر أعلى للمواصفات نفسها (~2000–4500 دج/شهر) وجودة متفاوتة — لكن الدفع المحلي والدعم بالعربية يعوّضان في البداية، والـping داخل الجزائر ممتاز (5–20ms).

### لا ننصح به الآن
- أمريكا/آسيا (زمن استجابة سيئ)، Oracle Free (تسجيل عشوائي وغير مضمون)، Contabo كخيار أخير فقط (رخيص لكن شبكة مزدحمة أحياناً).

## بعد الشراء (ينطبق على أي مزود)

```bash
# 1) تحديث + مستخدم + جدار ناري
apt update && apt upgrade -y
adduser deploy && usermod -aG sudo,docker deploy
ufw allow 22/tcp && ufw allow 80/tcp && ufw allow 443/tcp && ufw enable

# 2) Docker
curl -fsSL https://get.docker.com | sh

# 3) المشروع (انظر docs/DEPLOY.md للتفاصيل الكاملة)
git clone <repo> /opt/dzsaas && cd /opt/dzsaas
cp .env.example .env && nano .env   # كل الأسرار + النطاقات
docker compose up -d --build
```
