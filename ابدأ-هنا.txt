دكّان برو — التشغيل المحلي على جهازك
=====================================

المتطلب: Node.js 20 أو أحدث من https://nodejs.org (نسخة LTS).

الخطوات (نافذة PowerShell داخل هذا المجلد):

  1) npm install
     (مرة واحدة فقط — تثبيت المكتبات، يأخذ 2-3 دقائق)

  2) npm run dev
     (يبقى يعمل — لا تغلق النافذة)

  3) افتح في المتصفح: http://localhost:5173

الدخول للوضع المتصل (زر «دخول المشتركين» أعلى الصفحة):
  المعرف : demo-resto
  الهاتف  : 0550000000
  السر    : demo1234

بوابة الزبون (جرّبها في تبويب ثانٍ):
  http://localhost:5173/o/demo-resto/menu?t=2

للإيقاف: اضغط Ctrl+C في نافذة التشغيل.

حلول سريعة:
- «تعذّر الاتصال بالخادم» = نافذة npm run dev مغلقة أو الخادم لم يكتمل الإقلاع (انتظر 20 ثانية).
- المنفذ مستعمل (5173/4000) = أغلق أي نسخة قديمة تعمل.
- لا تفتح ملفات dist بالنقر المزدوج — يجب المرور عبر http://localhost:5173.
